## 구조 커버리지 축 (업무 분모에 합산 금지)

- CLI route 명령 `evidence/routes.txt`: 120 route rules / 91 distinct endpoints. Blueprint 그룹 관측: forum 50, management 39, auth 9, conversations 12, user 7, portal 1, static 1, themes 1 (route aliases로 group 합은 distinct endpoints와 같지 않을 수 있음).
- Source coverage lock `v0.1` (same fixed upstream SHA + installed official conversations/portal plugins): route groups map to F01/F03/F04/F05/F06/F07/F08 (forum read/profile/manage/post/marker/search/report), F02 (auth 9), F04/F08/F10/F11 (management categories/forums, reports, users/groups, settings/plugins/Celery/status JSON), F03/F10 (user profile/settings/admin user actions), F09 (all 12 conversation actions including `raw_message`), F12 (portal), and F16 (`static`/`_themes`). Duplicate URL aliases remain one logical endpoint and no count is converted into a feature count. `source-handler-map.txt` preserves source handler/render/action locations; route map includes every observed route rule, including JSON actions and aliases.
- Non-route source families are separately in-scope: `cli/main.py` install/populate/reindex/upgrade/celery/shell/urls/makeconfig, `cli/users.py` new/update/delete, and `cli/translations.py` new/update/compile → F13; three Celery email tasks and SMTP config → F02/F14; Whoosh/Whooshee rebuild and query consistency → F07/F15; installed plugins and hook registrations → F09/F12/F16; PostgreSQL/Alembic, Redis, local index and static/theme assets → F13/F17/F16. Source scan over fixed core and installed plugins found no route/handler for WebSocket/SSE, file upload/download, or public REST API (`FileStorage`, `request.files`, `send_file`, `send_from_directory`, socket/websocket markers had no matches); do not invent such a runtime feature. This negative source finding does not remove route-backed raw-content views.
- Coverage status: every one of the 91 observed distinct endpoints has at least one F01–F16 home above, and non-route operational behavior is assigned to F02/F07/F09/F12–F17. This locks the source-derived v0.1 denominator; individual route, role, error/empty-state, async and DB semantics remain unobserved or unimplemented as marked in their rows. No completion percentage is inferred from this inventory.
- PostgreSQL: 19 앱 테이블 (`categories`, `conversations`, `forumgroups`, `forums`, `forumsread`, `groups`, `groups_users`, `messages`, `moderators`, `plugin_registry`, `plugin_store`, `posts`, `reports`, `settings`, `settingsgroup`, `topics`, `topicsread`, `topictracker`, `users`) + `alembic_version`.
- fixture seed: users 5, groups 6, categories 2, forums 4, topics 4, posts 8, conversations 0. 다른 role/데이터 상태는 각 gate에서 추가 생성.
- 별도 검사할 외부 인터페이스: Flask HTML/forms, `flaskbb` CLI, SMTP+Celery async task, Redis broker/cache, PostgreSQL, Whoosh local search index, plugin API, theme/static assets. 원본에 실시간 push/WebSocket 또는 public JSON REST가 있는지는 source-wide audit에서 부재 증거를 확인한 뒤 기록한다.
- 원본 UI/controller source pass: `evidence/source-handler-map.txt`에 auth/forum/management/user 및 conversations/portal의 route decorator, handler, `render_template`, `jsonify`, celery/plugin hook 사용 지점을 line 단위로 보존. 현재 열거한 뷰 모듈에서 `render_template` 호출 90곳을 찾았으나 호출 수는 distinct 화면 수나 완전한 테스트 분모로 합산하지 않는다. 전체 91 endpoints의 F01–F16 분류와 고정 원본의 CLI/plugin/메일/search/DB·broker/asset source families 연결을 검토해 v0.1 scope denominator를 잠갔다. 이것은 per-screen UI/status, role/error, state/DB semantics를 전수 관측하거나 시험했다는 뜻이 아니다.

## 의미 보존 gate

각 ID는 같은 fixture와 권한 역할로 원본/AIP 양쪽 UI 요청, DB 전후 상태, 성공·거부 결과를 대조한다. 거부 시 행·관련 카운터가 변하지 않아야 한다. restart 이후 데이터·검색/추적 상태 보존도 별도 검증한다. 외부 SMTP/OIDC 실제 provider를 구성하지 않으면 그 통합은 미실행으로 남는다. 원본 보안 약점이 있어도 AIP 인가를 약화해 복제하지 않고 호환 가능한 차이로 명시한다. 전체 frontend가 AIP SDK만 호출하고 원본 업무 backend 중단 상태에서 작동해야 한다.
