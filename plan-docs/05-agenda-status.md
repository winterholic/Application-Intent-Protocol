## 이전 의제 판정 이력

아래 구현/완료 표기는 당시 PoC 관찰·감사 상태다. 독립 서버와 metadata의 의미를 미정으로 남긴 옛 판정은 최신 원문으로 대체됐다. 현재 구현 재확인은 [A](alignment/A-founder-intent-matrix.md)를 따른다.
