# decisions: 결정 문서 목록

> 한 문서에 주요 의사결정 하나. 새 상태 기준은 [B §5](../alignment/B-decision-reclassification.md#5-dd-문서의-현재-처리-상태)다. 기존 에이전트 리뷰·추천은 이전 지침의 검토 이력이며, 충돌하면 창시자 통합 지침과 B의 확정 기준을 우선한다.

순서는 기존 주제 연결을 위한 편집 순서다. 창시자 Q3(A형 원본)과 Q5 설명 대기는 해제됐다. 독립 `.aip` 파일 여부와 Typed IR 등 기술 상세는 답으로 단정하지 않고 각 문서에서 검증한다.
