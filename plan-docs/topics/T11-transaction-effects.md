> 이전 기준의 초안 상태: v0 (2026-10-03). 기준 원문: PART I §5, 의제 13. 당시 검토 대상으로 표시했으며, 현재 기술 검증 범위는 B를 따른다.
> **관련 기술 기록:** `../decisions/DD-07-bulk-success-unit.md`, `DD-02-write-scope.md`, `DD-09-read-side-effects.md` — 기존 리뷰는 이전 지침의 검토 이력이다. 현재 결정 상태는 [B](../alignment/B-decision-reclassification.md)를 따른다.

| 2 호출자 범위 | 조합 쓰기를 허용하면(T01 B·C) 트랜잭션 경계를 누가 정하나가 문제 |

| 7 수단 | 해당 없음 |

## 2. 다룰 항목 (원문 의제 13)

| 항목 | 현재 PoC | 초안 |
|---|---|---|
| 트랜잭션 경계 | 선언 Command 하나 = DB 트랜잭션 하나 | 조합 쓰기는 요청 하나 = 트랜잭션 하나 후보 |
| 여러 작업의 원자성 | DB 안은 원자적. 외부 효과는 원자적이라 가장하지 않는다 | 유지(옛 D-R3) |
| 외부 API 호출 | 효과 등급(local / staged / reservable / deferred / observational) + outbox | 유지 후보. 등급 이름과 의미 재검토 |
| 이벤트 발행 | outbox 기반 | 유지 후보 |
| 재시도 | 디스패처 재시도, 웹훅 재시도 곡선 | 유지 후보 |
| 중복 실행 방지 | 멱등 키, 처리 기록 테이블 | 유지 후보 |
| 보상 트랜잭션 | `on failure` 문법만, 실행 안 됨 | `[미정]` 옛 OI-X1 |
| 장기 실행 작업 | job(배치 커밋, heartbeat, 최소 1회) | 유지 후보 |
| 부작용 선언·검증 | 효과 서명 | 확장(T09)과 같은 서명 체계로 |
